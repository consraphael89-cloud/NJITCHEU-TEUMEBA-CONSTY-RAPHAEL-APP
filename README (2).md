# 🏥 MedTrack – Système Hospitalier

Application web Streamlit de collecte et analyse des données médicales.

## Installation

```bash
pip install -r requirements.txt
```

## Lancement

```bash
streamlit run app.py
```

## Fonctionnalités

| Page | Description |
|------|-------------|
| 🏠 Accueil | Tableau de bord avec statistiques en temps réel |
| 📋 Inscription | Formulaire complet données personnelles + médicales |
| 🩺 Diagnostic | Analyse des symptômes + mise à jour dossier |
| 👥 Patients | Tableau avec recherche et filtres avancés |
| 📊 Statistiques | Graphiques épidémiologiques par zone |

## Données

Les données sont stockées localement dans `/tmp/medtrack_patients.json`.
